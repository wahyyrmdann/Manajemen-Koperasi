# Manajamen - Koperasi

## Deskripsi
Sistem Manajemen Inventaris Koperasi adalah aplikasi berbasis web yang dirancang untuk mendigitalisasi proses pengelolaan persediaan barang di koperasi yang sebelumnya dilakukan secara manual menggunakan buku atau Microsoft Excel. Sistem ini dibangun menggunakan PHP Native dengan arsitektur three-tier dan basis data MySQL.

Aplikasi ini bertujuan untuk:
- Digitalisasi dan Otomatisasi Stok: Menggantikan pencatatan manual dengan sistem digital yang dapat menghitung dan memperbarui jumlah persediaan barang secara otomatis dan terintegrasi setiap kali transaksi divalidasi.
- Mengatasi Permasalahan Operasional Gudang: Meminimalkan ketidaksesuaian antara catatan stok dan jumlah fisik barang, mencegah keterlambatan pencatatan barang masuk dan keluar, serta mempermudah pemantauan ketersediaan barang.

## Persiapan
1. Clone repository.
2. Siapkan web server lokal menggunakan XAMPP.
3. Pastikan Apache dan MySQL sudah berjalan.
4. Buat database sesuai dengan skrip SQL yang tersedia di folder database.
5. Import file database ke phpMyAdmin.
6. Sesuaikan konfigurasi koneksi database dengan pengaturan lokal.
7. Jalankan aplikasi melalui browser menggunakan localhost.
